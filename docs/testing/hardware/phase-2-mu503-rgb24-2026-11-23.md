## Scope and limitations

This record verifies the common frame contract for the observed MU503 **RGB24 live-frame path** at the exact revision above. It does not establish:

- RAW frame identity, significant sensor depth, or storage width.
- Metadata availability in other camera modes or models.
- A resolution-table index; only the reported dimensions are known.
- Another AmScope model's behavior.
- A long-duration stability or full lifecycle acceptance test.

If the MU503's RAW mode is confirmed and included in the release claims, capture a separate RAW frame through `AmcamCamera` and record its `FRAME` line. If this model/configuration does not expose a usable RAW live mode, record that limitation instead.
